Die Marquis-Methode bestimmt BTM eindeutig über eine Farbreaktion. Sie wird sowohl als Substanztest im Einsatz als auch für die chemische Analyse im Labor (siehe BTM Laboranalysen) verwendet.

## Reagenz

Das Reagenz ist eine Lösung aus konzentrierter Schwefelsäure und Formaldehyd:

- **1 Teil** Formaldehyd
- **20 Teile** Schwefelsäure

## Durchführung

1. Marquis-Reagenz bereitstellen.
2. Die Probe zerkleinern (z. B. Tabletten im Mörser).
3. Eine kleine Menge der Probe in das Reagenz geben.
4. Ca. **20 Sekunden** reagieren lassen. In dieser Zeit reagiert die Lösung mit dem BTM und es entsteht eine Farbreaktion.
5. Die Farbveränderung beobachten und mit der Farbtabelle abgleichen.

## Farbtabelle

| Substanz | Farbreaktion |
| --- | --- |
| Crystal Meth | hellgelb → orange → lachsrot |
| Amphetamine | orange bis bräunlich |
| Kokain | hellrot → rot → dunkelrot |
| Lysergid (LSD) | türkis → blau → dunkelblau |
| Ecstasy (MDMA) | altrosa → purpur → violett |
| Cannabis (THC) | hellgrün → grün → olivgrün |
| Heroin | gelb → ocker → braun |
| unbekannte oder stark gestreckte Substanz | keine oder unklare Reaktion |

> **Hinweis:** Je stärker die Farbreaktion, desto höher die Reinheit bzw. die Qualität.
